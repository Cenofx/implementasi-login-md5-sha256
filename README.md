### Deskripsi Program

Program ini merupakan sistem login sederhana yang menerapkan algoritma hashing MD5 dan SHA-256 untuk meningkatkan keamanan password pengguna.

### Fitur

- Registrasi akun
- Login pengguna
- Penyimpanan data user menggunakan JSON
- Hashing password menggunakan MD5
- Hashing password menggunakan SHA-256
- Verifikasi login
